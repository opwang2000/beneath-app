Support

Beneath is a free focus app for the Mac (macOS 15 or later, Apple silicon). It has no account, no network and no in-app purchases. It can be used entirely with VoiceOver, Voice Control or the keyboard.

Contact: email beneathsupport@gmail.com with any question, problem or suggestion. Every message gets a reply, usually within a few days. (If you have a GitHub account, you can also open an issue.)

支持

Beneath 是一款免费的 Mac 专注应用（需要 macOS 15 及以上、Apple 芯片）。没有账号，不联网，没有任何内购，可以完全用旁白（VoiceOver）、语音控制或键盘操作。

联系方式：有任何问题、故障或建议，请发邮件到 beneathsupport@gmail.com，每封都会回复，通常几天内。（有 GitHub 账号的话，也可以在这里提交。）
